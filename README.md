# Portfolio - Testeuse informatique junior

Portfolio personnel présentant mon parcours, mes compétences et mes projets réalisés dans le cadre de ma formation de testeuse informatique.

## Présentation

Ce portfolio permet de découvrir :

* mon parcours et mon profil ;
* mes compétences techniques ;
* mes différents projets ;
* les outils et technologies utilisés ;
* mes coordonnées professionnelles.

## Projets présentés

### Tomsen

Application de gestion financière.

Travaux réalisés :

* revue des exigences ;
* stratégie de test ;
* cahier de recette.

### Eco Bliss Bath

Application e-commerce.

Travaux réalisés :

* automatisation de tests avec Cypress ;
* tests fonctionnels ;
* tests API ;
* smoke tests ;
* tests de sécurité XSS.

### Kasa

Application de location immobilière développée avec React.

Travaux réalisés :

* développement de composants React ;
* création de fonctionnalités interactives ;
* mise en place de la navigation entre les pages.
